# Jogo Pedra, Papel e Tesoura

Este é um jogo simples de **Pedra, Papel e Tesoura** criado com HTML, CSS e JavaScript. O jogo permite que o usuário jogue contra o computador, com as opções de **Pedra**, **Papel** ou **Tesoura**. O jogo apresenta os resultados de forma interativa e animada.

## 🎮 Como Jogar

1. Escolha entre **Pedra**, **Papel** ou **Tesoura** clicando nas opções exibidas na tela.
2. O computador irá fazer sua escolha aleatória.
3. O resultado será exibido mostrando se você venceu, perdeu ou empatou.
4. O jogo pode ser jogado quantas vezes você desejar.

## ⚙️ Tecnologias Usadas

- **HTML**: Para estruturar a página e o conteúdo.
- **CSS**: Para estilizar o layout e os efeitos visuais.
- **JavaScript**: Para a lógica do jogo e a interação do usuário.

## 🎨 Funcionalidades

- **Escolha do usuário**: O usuário pode escolher entre Pedra, Papel ou Tesoura clicando nas opções.
- **Escolha do computador**: O computador escolhe aleatoriamente entre as três opções.
- **Animações**: Efeitos visuais quando o jogador faz a escolha e o resultado é exibido.
- **Exibição do resultado**: O resultado do jogo (vitória, derrota ou empate) é exibido de forma clara e interativa.
